# blaq_reel

Promo videos made from a Flutter app's real screens: layers in 3D, a
keyframed camera, moving type, rendered frame by frame in `flutter test`
and encoded by FFmpeg.

This is the package: the engine (`package:blaq_reel/blaq_reel.dart`), the
style packs (`package:blaq_reel/packs.dart`) and the command line
(`dart run blaq_reel …`) with the studio.

**The full guide is the repository's [README](../README.md):** setting it
up in an app, the studio and its builder, the spec format, the command
line, the building blocks, and troubleshooting. What changed, release by
release, is in [CHANGELOG.md](CHANGELOG.md).

```bash
flutter pub get && dart analyze && flutter test
```
